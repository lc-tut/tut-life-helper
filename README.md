# tut-life-helper
東京工科大学の学生・来場者向けキャンパス生活支援webアプリ
# 経緯
現在、本家リポジトリ制作者であるよしくんのスケジュールおよび、Vercel Hobbyプランの制約（チーム開発の制限）を考慮し、一時的にこのフォーク版側で先行して機能開発を進める方針をとっています。よしくんのスケジュールが空き次第、本家リポジトリへのマージ（統合）を行い、共同開発に戻る予定です。
# 謝罪
本家リポジトリからいくつかのIssueをこちらに移行（コピー）しましたが、GitHubの仕様上、すべてのIssueの作成者が私（操作者）の表示になってしまっております。
Issueを作成してくださった先輩方、作成者の表示が変わってしまい誠に申し訳ありません。
元々のIssueは、本家の [GitHub Issues](https://github.com/lc-tut/tut-life-helper/issues) からご確認いただけます。
